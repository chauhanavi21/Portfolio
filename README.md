# Avi Chauhan | Portfolio

Personal portfolio built with React, Vite, Tailwind CSS v4 and Motion.

Live site: https://chauhanavi.com

## Run locally

```bash
npm install
npm run dev
```

If `npm install` fails on peer dependencies, use `npm install --legacy-peer-deps`.

## Build

```bash
npm run build
```

The production build is written to `dist/`. The included `public/.htaccess` is set up for IONOS hosting (HTTPS redirect, caching, compression).

## Edit the content

All text lives in [`src/data.js`](src/data.js): profile, projects, skills, experience, education and FAQ.
